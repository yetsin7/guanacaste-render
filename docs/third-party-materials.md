# Materiales de Poly Haven

Los materiales incluidos usan mapas de color, normales OpenGL y rugosidad de 2K de Poly Haven, distribuidos bajo CC0: https://polyhaven.com/license. Las descargas se comprobaron con el MD5 publicado por el proveedor. Los mapas de roble y estuco se convirtieron de JPEG a PNG para que el decodificador de Windows los pueda abrir; los demás archivos se mantienen originales.

- https://polyhaven.com/a/brick_wall_001
- https://polyhaven.com/a/concrete_wall_001
- https://polyhaven.com/a/oak_wood_planks
- https://polyhaven.com/a/clay_plaster

El tamaño inicial de repetición (2 m) es orientativo y se puede ajustar en el editor para adecuarlo a la geometría. Las normales simulan detalle de superficie; no desplazan la geometría.
